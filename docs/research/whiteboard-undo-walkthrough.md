## 1. Scope spike 结论（迁移前实证）

以真实 yjs@13.6.32 对 `Y.UndoManager` 逐项验证（node 脚本 + 落地为 spec 用例）：

| 问题                   | 结论                                                                                                                   |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| scope 怎么选           | doc 全域 + `captureTransaction` 白名单。白名单 = `changedParentTypes` 含 `pages`（元素变更的祖先链必含 pages，已实证） |
| 哪些写入被排除         | 视口（viewportOffset）、工具态（toolState）、翻页（currentPageIndex）、课件登记（fileList）均不含 pages → 不入栈       |
| 合并语义               | `captureTimeout: 0` → 逐事务独立成项（`now-lastChange < 0` 恒假），与旧栈「每笔一档」一致                              |
| origin                 | 默认 `trackedOrigins = {null}` 只捕获本地写入；远端同步（origin=provider 实例）与自定义 origin 均不入栈（已实证）      |
| 栈项 meta              | `stack-item-added` 写 `pageIndex`；栈项在 undo/redo 栈间移动是同一对象，meta 保留首次记录                              |
| redo 清空              | 新的捕获事务自动清 redo；视口/翻页等非捕获事务不清（与旧 `m !== 'move'` 语义对齐）                                     |
| 空栈 undo              | 返回 `null` → 沿用旧 toast 文案「没有更多撤销/没有更多重做」                                                           |
| 系统建页（进房默认页） | sync 后无页时的自动建页以 `origin=this` 写入 → 不入栈，保持「默认页不可撤销」旧语义                                    |

## 2. 迁移实现要点

- `YjsProvider` 新增 `undoManager`（scope=doc，白名单过滤，captureTimeout=0）与 `undo()/redo()/clearUndoStack()`；只读端恒返回 `null`。
- `WhiteBoard.vue` 删除手写 `undoStack/redoStack/UndoAction`（含 15 处 push/清理点），`revocation()` 只做 toast + 按 meta 跳页；`layerClear` 改调 `clearUndoStack()`；手动翻页 `showLayer` 保留「只清 redo」旧语义（`um.clear(false, true)`）。
- `applyShapeUpdate` 的「写字段 + 清残留键」合并为单事务——拆开会被逐事务成项拆成两档（圆形转椭圆撤销不完整），已修并有 spec 覆盖。

## 4. 已知语义变化（评审确认项）

1. **课件导入变为可撤销**：`openCourseware` 单事务导入原本不入手写栈（旧栈无对应项，撤销会误伤更早的操作）；现作为单个栈项整体撤销/重做——行为更符合直觉，属正向变化。
2. **首笔自动建页**：同步未完成时首笔触发的兜底 `addPage` 会成为独立栈项（旧栈无此项）。进房默认页以 origin 隔离不入栈，不受影响。
3. **删除页（delLayer）可撤销**：`removePage` 事务现入栈（旧栈无对应项）。
4. **updateElement 与 deleteElementKeys 合并为单事务**（applyShapeUpdate 处）：互斥字段提交的撤销从「拆两档」修正为「一档完整还原」。
