## 2. 逐项评审

### B1 批次

**F7.2 板书深色底（黑板模式）** ｜ 成本复核：维持"小"

- 规格：§4.7 — 页面背景切墨绿/黑板色，浅色笔迹；入口在现有清页菜单旁
- 方案/模块：页级属性（Yjs page map）→ `KonvaRenderer` 背景色绘制 + `WhiteBoard` 页面设置；默认笔色跟随提示
- 测试面：正 = 切换生效并同步学生端、与 undo 兼容；负 = 学生端只读不可切、旧客户端忽略未知页属性不崩
- 风险：与课件页底图共存需定义（初版建议仅空白页可切，课件页入口禁用）
- DoD 草案：切换 p95 即时同步；课件页/空白页行为写死；红灯 spec 2 条

**F3.6 方程式配平辅助** ｜ 成本复核：维持"小"

- 规格：§4.3 — 矩阵法求系数，公式浮层"配平"按钮，**不自动改写**
- 方案/模块：新纯函数 `whiteboard/balance.ts`（高斯消元 + 最小整数解）+ 公式浮层按钮（F1.2 化学模式已具备）
- 测试面：正 = `H2+O2→H2O` → 2:1:2、复分解典型式；负 = 不可配平式返回可读错误不抛异常、空/非法输入不崩
- 风险：`\ce` 解析范围（初版限定：元素/系数/条件箭头子集）
- DoD 草案：可配平式 100% 正确（测试集 ≥20 式）；红灯 spec 2 条

### B2 批次

**F7.3 聚光灯/放大镜** ｜ 成本复核：**升"中"（同步学生端，2026-10-11 拍板）**

- 规格：§4.7 — 遮罩 + 高亮窗口聚光；放大镜局部放大；工具栏开关、拖动窗口
- **已拍板（2026-10-11）**：聚光灯窗口与放大镜视口经 **awareness 广播**同步，学生端纯视觉跟随、不可交互；断线/无教师信号时学生端关态零残留
- 方案/模块：`WhiteBoard` overlay 层 + 放大镜走 canvas 区域重绘（stage.toDataURL 或离屏采样）+ awareness 字段（开关/窗口矩形/放大视口）；学生端只读渲染分支
- 测试面：正 = 开关/拖窗/放大倍率生效、awareness 广播学生端跟随、p95 ≤300ms；负 = 聚光层拦截点击（不穿透选中下层）、关态零残留、学生端收到广播也**不可交互**、断线后无幽灵遮罩
- 风险：放大镜在缩放/平移时的采样坐标换算；广播节流（拖动期 50ms 对齐激光笔惯例）
- DoD 草案：开关到可见 ≤100ms；同步 p95 ≤300ms；点击不穿透 100%；红灯 spec 2 条（同步 + 不穿透各 1）

**F7.4 板中板（叠加小黑板）** ｜ 成本复核：维持"中"

- 规格：§4.7 — 当前页叠加可收纳演算区，收纳为角标，内容随页保存
- 方案/模块：叠加层（HTML overlay 或独立 Konva stage）+ 页附属字段（Yjs page meta）存内容与开合态；`WhiteBoard` 呼出/收纳 UI
- 测试面：正 = 呼出书写收纳、翻页后各页内容独立、随页持久化；负 = 学生端只读且可见、主画布不被遮挡误触（z 序与命中）
- 风险：与主画布交互隔离；内容元素是否独立 Yjs 集合（建议独立，避免污染主页 elements）
- DoD 草案：内容随页保存恢复正确；开合态同步学生端；红灯 spec 2 条

**F4.8 蒙层/揭示** ｜ 成本复核：维持"中"

- 规格：§4.4 — 可拖遮罩块，**仅教师可点击揭开**；学生端纯视觉不可点不可穿透；选中态可拖/Delete
- 方案/模块：新 element type `mask`（`types.ts`）→ `KonvaRenderer` 绘制+命中分支、`WhiteBoard` 放置与揭开交互；前向兼容走 default 分支
- 测试面：正 = 放置→点击揭开（删除同步学生端）、拖动移开下层可见；负 = 学生端点击无效（只读矩阵 spec）、旧客户端遇 `mask` 忽略不崩（default 分支 spec）、Esc 取消放置
- 风险：揭开语义 = 删除元素则 undo 可恢复遮盖（是否可接受需在 spec 写死——建议可 undo）
- DoD 草案：双端行为矩阵 spec 覆盖；前向兼容 spec 1 条；红灯 spec 2 条

### B3 批次

**F2.4 度量标注** ｜ 成本复核：维持"中"

- 规格：§4.2 — 选中线段/角/图形显示长度/角度/面积，随调整实时更新；属性面板开关、标注可换色
- 前置：F2.3 点/线/多边形已完成 ✓
- 方案/模块：源元素加 `showMetrics` 标志（入 Yjs），**度量值在渲染端派生**（不同步数值，避免陈旧值）；`KonvaRenderer` 度量绘制 + `geoSnap` 邻近几何计算 + 属性面板入口
- 测试面：正 = 选中线段显长度、拖端点实时更新、多边形面积/角度；负 = 非几何对象无入口、退化（零长/共线）保护显示、关闭后无残留
- 风险：拖动期重算性能（采样阈值）；度量与 F5.2 快照/导出合成是否包含（建议含，入 DoD）
- DoD 草案：更新延迟 ≤1 帧（拖动中无肉眼滞后）；导出/快照含度量标注；红灯 spec 2 条

**F2.5 教具仿真（直尺/量角器/圆规）** ｜ 成本复核：维持"中"

- 规格：§4.2 — 可旋转/平移仿真实物，沿边画线、读角度读数
- 方案/模块：新 element 类型（可旋转 Konva Group，旋转手柄复用选择框交互）+ 笔迹层贴边生成；`types.ts`/`KonvaRenderer`/`WhiteBoard` 工具交互
- 测试面：正 = 呼出/旋转/平移/直尺贴边画线、量角器读数渲染；负 = 旋转角非法值钳制、教具跨页不残留、学生端只读
- 风险：旋转手柄与现有选择框冲突；贴边画线坐标换算（stage↔教具局部）
- DoD 草案：画线沿边误差 ≤2px；旋转 0–360° 连续；红灯 spec 2 条

**F1.4 四线三格/拼音格模板** ｜ 成本复核：维持"中"

- 规格：§4.1 — 格线对象，素材面板拖入，行高/颜色可调；**调参后自动锁定** + 锁定框边缘"解锁"按钮
- 方案/模块：新 element type `gridTemplate`（线组绘制）+ 素材面板入口（F3.3 assetStore 管线）；锁定复用 F2.1 已有锁定语义，解锁浮出按钮为新增 UI
- 测试面：正 = 拖入生成、调参、自动锁定、边缘解锁后再选中编辑；负 = 锁定态不可选中/不可拖（已有 spec 模式）、课件页可用、学生端只读
- 风险：三种格线（四线/拼音/田字）绘制差异；锁定态描边与解锁按钮的命中区域
- DoD 草案：锁定→解锁闭环无死角；三格线渲染正确；红灯 spec 2 条

**F4.7 思维导图** ｜ 成本复核：维持"中"

- 规格：§4.4 + §11.2 — 节点+连线；**仅导图工具激活时**双击空白建根节点（4.9.2 真值表）；Tab/Enter 增子/同级；**自动布局初版不做**（手动摆位）
- 方案/模块：新 element type `mindmap`（节点组 + 连线）；`WhiteBoard` 工具态与键盘交互；节点文本复用文本管线
- 测试面：正 = 工具态双击建根、Tab/Enter 增节点连线跟随、整组选中移动；负 = 非工具态双击不触发（与文本双击冲突验证）、学生端只读、Esc 退工具态
- 风险：双击真值表与文本/图片双击冲突（4.9.2 必须 spec 化）；节点文本编辑态
- DoD 草案：真值表三态全覆盖 spec；连线随动无抖动；红灯 spec 2 条

**F6.5 微课录制（屏幕+板书）** ｜ 成本复核：维持"中"

- 规格：§4.6 — 录制教师屏幕/白板为视频，Electron 管线，与直播录制能力可能复用
- 方案/模块：主进程 `desktopCapturer` + MediaRecorder（或评估复用 Janus 录制链路）→ IPC（`packages/ipc`）→ 本地 webm；renderer 开始/暂停/停止 UI
- 测试面：正 = 开始/暂停/停止 IPC 序列与状态机；负 = 录屏权限拒绝提示（§4.9 异常态）、重复启动防抖、停止时文件未就绪的等待态
- 风险：**jsdom 无法覆盖真实录屏**（手动验收为主）；文件体积/帧率选型
- DoD 草案：状态机 spec 全覆盖；真实录制产物可播放（手动）；红灯 spec 2 条

### B4 批次

**F5.3 多媒体嵌入（音视频片段）** ｜ 成本复核：维持"中-大"

- 规格：§4.5 — 页内播放器；工具栏选文件/URL；**学生端同步 play/pause**；§11.2 初版直链/本地文件不转码
- 方案/模块：新 element type `media`（引用 + 尺寸位姿）；播放器以 DOM overlay 对齐 stage（视口联动是核心难点）；播放状态存 Yjs meta（教师写、学生跟）
- 测试面：正 = 插入渲染、播放/暂停状态跨端同步、翻页后位置正确；负 = 文件缺失/URL 失败占位（§4.9）、学生端不可控播、视口缩放平移后 overlay 对齐不漂、超长文件时长提示
- 风险：**视口联动**（缩放/平移/翻页三态对齐）为最大风险；同步时钟漂移；文件选择复用课件上传管线与否待实现期定
- DoD 草案：三态对齐误差 ≤2px；状态同步 p95 ≤300ms；红灯 spec 2 条（同步 + 对齐各 1）
